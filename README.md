# YOLO 标注训练工具

基于 PySide6 + ultralytics 的 Windows 桌面端 YOLO 标注训练一体化工具：标注、数据集管理、AI 辅助标注、训练、导出、推理，全流程一站式完成。

## 功能特性

### 标注（四种任务类型）
- **矩形框**（检测 YOLOv8/v11）
- **多边形分割**（YOLO-seg，顶点级编辑）
- **关键点**（YOLO-pose，骨骼连线可视化、可见性标记）
- **旋转框 OBB**（YOLOv8-obb，旋转手柄）
- 缩放/平移/十字准星、撤销重做、复制粘贴、类别快捷键、切图自动保存
- **多选批量移动**：Ctrl+点击多选后拖动任一标注整体移动
- **右键菜单**：删除/复制/粘贴/原位复制/更改类别
- **图片面板**：缩略图浏览、按名称搜索、按已标注/未标注过滤
- **开始页**：启动欢迎页，一键新建/打开数据集，最近项目直达，记住上次浏览位置

### 数据集管理
- 一键创建数据集（自动生成 images/labels 标准结构）
- 一键划分 train/val/test（比例可配），自动生成训练用 data.yaml
- 数据集统计（图片数、每类实例数、标注类型分布）
- VOC XML / COCO JSON → YOLO 格式转换、标注可视化导出

### AI 辅助标注
- **模型预标注**：用已训练模型批量打框，人工只需修正
- **SAM 智能分割**：正点/负点/框提示一键生成精确多边形掩码（MobileSAM 轻量模型，首次使用自动下载）

### 训练（完整生命周期）
- 模型选型（YOLOv8/v11 全系：检测/分割/关键点/OBB）
- 训练参数配置（epochs/batch/imgsz/lr/设备），自动检测并显示 GPU 型号
- **实时损失曲线**（pyqtgraph）、训练日志
- 导出 ONNX / OpenVINO / TensorRT / TFLite / CoreML
- 模型推理测试（单图/文件夹/视频），训练完成后自动填入最佳权重

### 主题
- 默认**浅色主题**，内置**深色主题**，设置面板运行时热切换，自动保存
- 启动自动打开上次数据集（可在设置中关闭）

## 快速开始

### 1. 安装（仅需一次）

双击运行 **`setup.bat`**

脚本会自动：
1. 检测 Python 3.11（缺失则通过 winget 自动安装）
2. 在项目内创建 `.venv` 虚拟环境（不污染系统）
3. 安装全部依赖（国内镜像加速，含 CUDA 版 PyTorch）

> 首次安装需下载约 3GB 依赖文件，请耐心等待。

### 2. 启动

双击运行 **`start.bat`**

### 3. 使用流程

1. **新建数据集**：`文件 → 新建数据集`，选择目录、填写类别（逗号分隔）、选任务类型
2. **导入图片**：`文件 → 导入图片`
3. **标注**：工具栏切换工具，快捷键见下
4. **划分数据集**：`数据集 → 划分训练/验证/测试集`
5. **训练**：主窗口「训练」页签，选模型与参数，开始训练
6. **导出/推理**：训练面板导出模型；「推理测试」页签做单图/视频推理

## 目录结构

```
DS4YoloLabelAndTrainTools\
├── app\              # 源码（core 业务逻辑 / ui 界面）
├── tests\            # 自测脚本
├── models\           # SAM 等模型缓存（自动下载）
├── logs\             # 运行日志
├── requirements.txt
├── setup.bat         # 一键安装
├── start.bat         # 一键启动
└── config.json       # 用户配置（主题、最近项目等，自动生成）
```

数据集目录结构（由工具自动维护）：

```
数据集\
├── dataset.json      # 类别与任务类型
├── data.yaml         # 训练配置（划分后生成）
├── images\           # 原始图片
│   └── train\ val\ test\   # 划分后
└── labels\           # YOLO txt 标注
    └── train\ val\ test\
```

## 环境要求

- Windows 10/11
- NVIDIA 显卡（CUDA 可用，训练加速；无 GPU 也可用 CPU 训练）
- 无需预装任何环境（setup.bat 全自动）

## 常见问题

**Q: 训练时提示显存不足？**
减小 batch size 或 imgsz，训练面板中调整即可（8GB 显存建议 batch ≤ 8）。

**Q: SAM 分割首次使用很慢？**
首次使用会自动下载 MobileSAM 模型（约 40MB）到 models 目录。

**Q: 程序异常退出？**
查看 `logs/app.log` 日志文件定位问题。

**Q: 想换训练输出目录？**
训练面板中"实验名称"即输出子目录名，训练结果保存在数据集目录下。
